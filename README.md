## 一、运行方式

1. 双击 `index.html`，浏览器即可秒级打开；
2. 默认「单摆模式」：屏幕中央出现平滑摆动的单摆；
3. 下方面板可拖动三个滑块（摆长 100~350px、重力 1~25、阻尼 0~0.010）实时调节物理表现；
4. 点击「重置摆动」按钮，摆球精准回到 45° 初始状态；
5. 按 `F12` 打开控制台，应显示 **0 红色报错**。

### 进阶挑战 A：双摆混沌模拟器（选做，+10 分）

- 点击顶部「双摆混沌」按钮切换到双摆模式；
- 采用 **Runge-Kutta 4 阶（RK4）数值积分**精确求解双摆非线性微分方程，翻转流畅无发散；
- 第二个摆球带**半透明彩虹渐变拖尾（Trail Effect）**，直观展现混沌运动轨迹；
- 支持**鼠标拖拽第二摆球**改变初始角度，释放后立即进入混沌摆动。

### 2. 闭环控制反思

**当遇到报错或动画停滞时，你是如何定位问题的？**

> （例如：按 F12 打开控制台，复制完整红字堆栈
> `Uncaught ReferenceError: resetAnimation is not defined`，而不是
> 笼统说「坏了重写一遍」。）

**AI 的修复方案中，你是否看懂了它是如何通过修改物理公式或边界条件解决的？**

> （例如：看懂了。阻尼项 `-k·ω` 是「与角速度成正比、方向相反」
> 的阻力，所以 k 越大摆幅衰减越快；重力 `g` 增大时角加速度
> `α = -(g/L)·sinθ` 的系数变大，摆动更快。这些都是从物理公式层
> 面，而非「乱调参数」解决的。）
